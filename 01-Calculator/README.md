# 🧮 Iterative Calculator (C#)



A console-based arithmetic calculator built to demonstrate progressive C# development—evolving from basic procedural control flow to clean OOP architecture and decoupled interfaces.



## ✨ Core Features

\-  \*\*Basic Arithmetic:\*\* Performs addition (`+`), subtraction (`-`), multiplication (`\*`), and division (`/`).

\-  \*\*Safe Input Handling:\*\* Uses `TryParse` and operator validation to prevent runtime crashes on invalid inputs.

\-  \*\*Error Protection:\*\* Detects and blocks division by zero with clear user feedback.

\-  \*\*Continuous Session:\*\* Loops smoothly for multiple consecutive calculations until the user exits.



## 📈 Version Roadmap

\- \[x] \*\*`v1-Basics`:\*\* Procedural implementation in `Main`, loops, `switch` cases, and `TryParse` validation.

\- \[x] \*\*`v2-Methods`:\*\* Refactoring into single-responsibility helper methods.

\- \[ ] \*\*`v3-OOP`:\*\* `CalculatorEngine`, `IOperation` polymorphism, encapsulated history, and exception handling.

\- \[ ] \*\*`v4-Advanced`:\*\* Decoupled Windows Forms UI powered by the core engine.
